# Implementation plan

1. Phase 1A: môi trường cô lập, FFmpeg, PyTorch GPU, NSFW scanner, báo cáo và storage dry-run.
2. Phase 2: benchmark riêng NSFW, blood/gore, violence và text/logo.
3. Phase 3: edit plan, preview và FFmpeg export có kiểm tra A/V.
4. Phase 4: xác minh Creator Center và upload POC không tự publish.
5. Phase 5: Telegram với allowlist và secret store.
6. Phase 6: end-to-end state machine, checkpoint và chống job trùng.
7. Phase 7: reliability, archive HEVC và retention automation.

Mỗi phase phải đạt acceptance criteria trước khi mở rộng phạm vi.
